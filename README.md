# YAML Viewer

A simple static page that renders YAML from URL query parameters. Includes a copy-to-clipboard button. Hosted on GitHub Pages.

## Usage

Pass any key-value pairs as query parameters and they will be templated into the displayed YAML.

```
https://ricardo-mng.github.io/yaml-viewer/?req_cpu=1960m&req_mem=5700Mi&lim_cpu=3800m&lim_mem=8550Mi
```

## Hosting

Served via GitHub Pages from the `main` branch root.
